Microsoft Windows SDK import libraries
--------------------------------------

The Windows build links against operating-system APIs supplied by Windows.
Release binaries use the static Microsoft C/C++ runtime selected by CMake, so
the portable archive does not require users to install a separate Visual C++
Redistributable package.
