# Unified Workbench Queue

This queue is ordered by user-visible impact. Each item must pass Release and Debug tests, minimum/wide DPI visual QA, and the 100 MiB base-footprint gate before it is marked complete.

1. **One composer for every capability — complete.** Keep a single conversation and composer. Infer text, code, project, image, audio/music, and tool work automatically; keep a plain `Action` selector beside Send as an override. Media and file results remain in the same transcript.
2. **Simplify primary navigation — complete.** The primary surface is `Workspace`, `Settings`, and `Activity`. AI connections, learning, and capabilities are secondary Settings pages; storage and logs are consolidated under Activity without removing their functions.
3. **Conversational learning and memory — next.** Support plain-language correct/teach/remember/forget requests with an exact preview of what will be stored, rejected, trained, or kept as durable user memory. Keep per-reply controls as a backup.
4. **Bounded autonomous improvement.** Add a visible session budget (up to 12 hours), pause/resume/cancel, stage/resource status, retained evidence, and explicit separation between verified memory, native model training, PEFT fine-tuning, and optional specialist generation packs.
5. **Exact add-on audit.** Inspect and report the installed Transformers/PEFT pack file-by-file: purpose, size, version, origin, license, loading conditions, runtime/training role, redundancy, and safe removal rules.
6. **Unified specialists and safe self-coding.** Present English, coding, image, audio, tools, and future specialists as one EngCoder system while keeping capability internals isolated. Run self-coding only in a staged workspace with compile/test/evaluation evidence and atomic promotion.

Completed items remain subject to regression tests while later items are implemented.
