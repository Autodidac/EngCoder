# Unified Workbench Queue

This queue is ordered by user-visible impact. Each item must pass Release and Debug tests, minimum/wide DPI visual QA, and the 100 MiB base-footprint gate before it is marked complete.

1. **One composer for every capability — complete.** Keep a single conversation and composer. Infer text, code, project, image, audio/music, and tool work automatically; keep a plain `Action` selector beside Send as an override. Media and file results remain in the same transcript.
2. **Simplify primary navigation — complete.** The primary surface is `Workspace`, `Settings`, and `Activity`. AI connections, learning, and capabilities are secondary Settings pages; storage and logs are consolidated under Activity without removing their functions.
3. **Conversational learning and memory — complete.** Plain-language correct, teach, remember, forget, and memory-list requests execute locally and show exact receipts for storage, rejection, immediate verified recall, future candidate eligibility, and the hard boundary between durable user memory and model weights. Per-reply controls remain available as a backup.
4. **Verified learning and bounded weight training — complete.** Automatic idle learning continuously curates approved and independently checked evidence without a session timer. A separate `Compile data and retrain model` action serializes pending verified topics into isolated test models. Supervised-token budgets, behavior deduplication, bounded replay and step safety ceilings constrain each candidate; checkpoints preserve resumability while Chat retains priority and the working model remains online.
5. **Exact add-on audit — complete.** Inspect and report every installed optional add-on file: purpose, size, owning dependency/version, origin, license, loading condition, runtime/training role, confirmed byte-for-byte redundancy, dependency relationships, and safe removal rules. Uninstalled catalog entries explicitly report zero installed files and weights.
6. **Unified specialists and safe self-coding — complete.** Present English, coding, image, audio, tools, and future specialists as one EngCoder system while keeping capability internals isolated. Run self-coding only in a staged workspace with compile/test/evaluation evidence and atomic promotion.

7. **Truthful learning and model visibility — complete.** Separate bundled curriculum, held-out checks, automatic teacher attempts, and user reviews; identify the zero-weight native foundation separately from promoted neural weights; keep resize updates batched and responsive; and expose all foreground/background activity in one permanent global strip.

8. **Professional non-overpainting workspace — complete.** Page hosts paint rounded, accented card surfaces behind clipped native controls. A layout transaction commits before the active page is shown, and consistent inner spacing keeps Chat, review actions, the composer, the AI sidebar, and the neural-training explanation readable after Send, Retry, source changes, tab changes, and resize.

Completed items remain subject to regression tests while later items are implemented.
