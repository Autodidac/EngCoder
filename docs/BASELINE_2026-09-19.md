# EngCoder architecture baseline — 2026-09-19

This baseline records the design decision that led to the original modular-architecture redesign.

EngCoder is one local-AI product composed of a low-latency Architect controller, a persistent local KeyMaker Foundation, modular capability addons, deterministic native tools/policy, and a local training/evaluation lifecycle.

The design explicitly rejects two alternatives as the default architecture:

1. one increasingly large monolithic model that must learn every domain; and
2. several duplicated full chat models acting as independent agents.

Instead, shared language intelligence stays in the KeyMaker Foundation and narrow capability weights attach as independently routed lanes/components. Physical placement follows NVMe -> RAM -> VRAM with KeyMaker Foundation/Architect pinned and addons loaded on demand.

The previous local model/training application is incorporated as EngCoder's training/model foundry rather than left as a second product. The prior Web shell is incorporated as presentation code rather than left as a second orchestration layer.

Compatibility aliases may remain, but active product identity and current documentation are EngCoder.
